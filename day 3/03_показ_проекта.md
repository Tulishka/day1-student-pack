# Показ проекта за 3 минуты

Подготовьте страницу и два обращения заранее. Не показывайте на экране файл с API-ключом.

| Время | Что показать и сказать |
|---|---|
| 0:00–0:30 | Одним предложением: для чего нужен диспетчер и что делает ваша команда. |
| 0:30–1:15 | Отправьте обращение и покажите категорию, приоритет и уточнение. |
| 1:15–1:45 | Вручную исправьте один ответ. Покажите, что первоначальное решение модели сохранилось. |
| 1:45–2:30 | Назовите результаты первого прогона: категория __/12, приоритет __/12. Разберите одну ошибку. |
| 2:30–3:00 | Объясните одно улучшение и где человеку всё ещё нужно проверять ИИ. |

Если API в момент показа недоступен, покажите уже сохранённую строку таблицы или результаты проверки, честно назовите проблему и объясните, как приложение сообщает об ошибке. Не выдавайте учебный режим за живой ответ модели.
